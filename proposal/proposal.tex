\section*{Problem Statement}
How can robot policies be deployed efficiently on compute-limited edge devices while achieving both a high success rate and low latency?

\section*{Motivation}
Deploying reinforcement learning (RL) policies on robots is often bottlenecked by limited on-device compute. Quantization reduces this cost but can degrade performance. However, not all states demand the same precision: coarse motions tolerate errors that fine manipulation does not. We therefore propose to learn a routing framework that dynamically selects which precision model to use at each step.

\section*{Proposed Approach}
We will post-train multiple quantized versions of a robot policy at different bit-widths. We will then train a router in one of two ways:
\begin{enumerate}[label=(\arabic*)]
  \item \textbf{Supervised learning} on a labeled dataset generated by running the high-precision and quantized models on the same inputs.
  \item \textbf{Reinforcement learning}, treating the router as a policy.
\end{enumerate}

\section*{Evaluation}
We will evaluate the resulting system on:
\begin{itemize}
  \item task success rate,
  \item inference latency,
  \item energy usage, and
  \item roofline analysis.
\end{itemize}
